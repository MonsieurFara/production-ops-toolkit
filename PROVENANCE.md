# Origine et niveau de validation

Collection préparée le 6 octobre 2026 pour Robert De Lelli BEIDI.
Les thèmes proviennent de travaux et d'échanges d'exploitation antérieurs.
Les exemples publics ont été adaptés ou reconstruits avec des paramètres
génériques et des données fictives ; ils ne constituent pas une copie
d'un environnement d'entreprise.

`README.md` et le catalogue précisent les éléments récupérés, les
reconstructions, les propositions et les limites des vérifications.
Un script reconstruit n'est pas présenté comme le script exact exécuté
historiquement. Les scénarios qui nécessitent une plateforme réelle
restent à valider en laboratoire.

Les logiciels cités restent la propriété de leurs auteurs respectifs.
Aucun dépôt applicatif interne complet, document classifié ni jeu de données
de production n'est redistribué dans cette collection.
