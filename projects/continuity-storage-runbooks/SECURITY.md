# Sécurité

Les données d'exemple sont synthétiques. Paramétrer les environnements et
fournir les secrets hors Git : fichier protégé, gestionnaire de secrets ou
variable de processus. Les captures, journaux et sauvegardes produits par
les outils peuvent contenir des informations sensibles ; les conserver localement.

Pour signaler un problème, décrire un cas reproductible avec des données
fictives. Ne publier aucun secret dans une issue. Si un secret a été exposé,
le révoquer et le remplacer : supprimer une ligne de Git ne suffit pas.
